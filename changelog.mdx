## Upgrade Instructions

Follow these steps to ensure you run the latest version of Nothing2Install integrations.

<Steps>
  <Step title="Check Current Version" icon="check-circle">

    Log in to your dashboard and navigate to Settings > Version.

  </Step>
  <Step title="Update SDK" icon="download">

    <CodeGroup tabs="JavaScript,Android">
      ```javascript
      // Update to v2.0.0
      npm install nothing2install-sdk@2.0.0
      ```
      ```kotlin
      // In build.gradle
      implementation 'com.nothing2install:sdk:2.0.0'
      ```
    </CodeGroup>

  </Step>
  <Step title="Restart Sessions" icon="refresh-cw">

    Redeploy your game portals or cloud instances to apply changes.

  </Step>
  <Step title="Verify" icon="zap">

    Test a demo stream at `https://minio-shared-ff.n2i-cache.xyz/superapp/pages/master/index.html?customer=n2i`.

  </Step>
</Steps>
